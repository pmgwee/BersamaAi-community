# Introduction Template (for #introductions)

Post this in `#introductions`, then **right-click the message → Apps/Pin** so every new
member sees it at the top. Post it from the **owner account** (a human), not the bot —
pinned official messages read as more authoritative.

The bot's welcome message already tells new members to "say hi in #introductions"; you
can optionally have it point them to this pinned template (small bot.py tweak — ask).

---

## ✅ Version A — English (recommended; matches the English-only server policy)

```
📢 New here? Drop a quick intro so we can welcome you!
Copy this template, fill it in, and post it below:

👋 Nickname:
🎓 Occupation / status:   (e.g. Student — Y1S3 · Working · Job-hunting · Solo founder)
📅 Year you started:   (work or studies)
💼 Career interest / field:   (what you're aiming for — "still exploring" is a great answer!)
🛠️ Other tech skills:   (languages & tools — "basic" is totally fine)
📚 Course / program:   (if you're studying)
📝 About me:   (a line or two — what are you into?)

No pressure to be an expert — BersamaAi is for everyone, beginners included. 🤝
```

### ✏️ Filled-in example (wilson)

👋 Nickname: wilson
